# 내 지갑

고등학생 용돈 기입장. 거래는 브라우저의 localStorage에 저장됩니다.

## 돈토리 AI 챗봇 배포

1. Vercel에서 이 저장소의 `master`를 연결합니다. Framework Preset은 Other, Root Directory는 저장소 루트입니다. 별도 빌드 명령은 필요하지 않습니다.
2. 프로젝트 Settings → Environment Variables에 `OPENAI_API_KEY`를 Production 환경으로 추가합니다. 키는 GitHub나 HTML에 넣지 않습니다.
3. 배포합니다. 환경변수 변경 후에는 다시 배포해야 합니다.
4. **Vercel 주소**에서 이번 달 거래를 입력한 뒤 소비 분석 탭에서 전송 동의에 체크하고 채팅 전송 버튼을 누릅니다. GitHub Pages에서는 서버 API가 실행되지 않습니다.

기본 모델은 `gpt-4.1-mini`입니다. 서버 환경변수 `OPENAI_MODEL`로 변경할 수 있습니다. API 사용 요금은 ChatGPT 구독과 별도입니다.

### 데이터와 제한

- 동의 후 사용자가 보낸 대화와 이번 달 수입·지출·카테고리별 합계, 전체 잔액, 기본 용돈, 남은 일수, 거래 건수를 전송합니다. 개별 거래와 메모는 전송하지 않습니다. 카테고리 이름에 민감한 정보를 쓰지 마세요.
- 오늘 이후 거래는 AI 집계에서 제외합니다. 하루 사용 가능액은 오늘을 포함한 남은 일수와 현재 잔액으로 서버에서 계산합니다. 미래 수입은 추정하지 않습니다.
- OpenAI Responses 요청에 `store: false`를 사용합니다. 이것이 제공자의 모든 데이터 보관을 없앤다는 뜻은 아닙니다.
- 대화는 페이지 메모리에만 보관하며 최근 6번의 문답을 다음 질문과 함께 전송합니다. 새 대화/새로고침 시 대화가 지워집니다. 거래가 없어도 상담할 수 있습니다.
- 브라우저의 중복 전송 차단, 서버 인스턴스별 IP 기준 3초 대기를 적용합니다. 서버리스 인스턴스 간 공유되지 않으므로 전역 사용량 제한이나 인증을 대체하지 않습니다.
- 현재 로그인 없는 공개 API입니다. 널리 공유하기 전에는 Vercel Firewall 등의 지속적인 요청 제한과 필요한 사용자 인증을 설정하세요. API 제공자의 사용량/결제도 확인하세요. Origin 검사는 인증이 아닙니다.
- 기존 사이트와 새 Vercel 주소는 localStorage를 공유하지 않습니다. 주소가 달라지면 기존 내역이 자동 이전되지 않습니다.

### 오류 해결

- 연결 설정 필요: Production의 `OPENAI_API_KEY`와 재배포 여부를 확인합니다.
- 인증 실패: 키와 API 프로젝트 권한을 확인합니다.
- 사용 한도/잔액 안내: API 결제 및 사용 한도를 확인합니다.
- 요청 후 3초 내 재시도: 잠시 기다린 뒤 다시 누릅니다.

## 검증

Node.js 22에서 `npm test`를 실행합니다. 실제 비용이 발생하는 API 호출 없이 요청 검증, 키 누락, 응답 처리, 타임아웃, 동의, 다중 턴, 재시도, 역할 검증, 메모 제외를 검사합니다.

돈토리는 친근한 반말과 행동에 대한 재치 있는 팩폭을 사용합니다. 인격/형편 비하를 금지하고 질문에 맞게 상담하도록 서버 지침을 설정했습니다. 모델의 실제 말투는 배포 후 확인하세요.
